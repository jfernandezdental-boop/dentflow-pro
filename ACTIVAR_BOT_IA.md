# Activar Bot IA (para el admin de la clinica)

## Enlace en el sistema

Abrir: **`activar-bot-ia.html`**

Recomendado en el menu:
- Configuracion → **Activar Bot IA**
- o Notificaciones → **Bot IA**

## Que hace el admin (sin comandos)

1. Entra a [console.x.ai](https://console.x.ai), crea API key, la pega
2. (Opcional) WhatsApp Meta o Twilio
3. (Opcional) SendGrid para proformas por correo
4. Interruptor **Bot IA activo** ON
5. **Guardar y activar**
6. **Probar conexion Grok**
